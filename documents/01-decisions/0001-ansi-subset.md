# ADR-0001: ANSI 覆盖度 — 核心子集

状态: accepted | 日期: 2026-07-31

## 背景
交互式终端需渲染 Linux/RTOS 输出，但完整 VT100/xterm 兼容工作量巨大、收益低。

## 决策
实现**核心子集**：SGR 图形渲染（16/256/真彩色 + 粗体/斜体/下划线/删除线/反色）、光标移动（上下左右/定位/保存恢复）、清屏清行（ED/EL）、滚动区域。P1 级插入/删除行列、字符操作。P2 级 OSC 标题。DCS/SOS/PM/APC 不实现，静默跳过。

## 理由
覆盖 90% 实际使用场景；交互式终端 + 传统收发分离的双模式，传统模式对完整序列需求低（自动染色让位）。

## 后果
- 不支持的序列 → 记录日志 + 静默跳过，绝不崩溃。
- ANSI 解析器为纯 Python 状态机，3.13 下吞吐足够（ADR-0006）。
