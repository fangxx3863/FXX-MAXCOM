# ADR-0005: GUI 框架 — DearPyGui

状态: accepted | 日期: 2026-07-31

## 背景
需要高频实时数据刷新（终端日志 + 波形图），内置绘图 API，打包体积小。

## 决策
GUI 用 **DearPyGui**（DPG）。GPU 加速渲染，内置 Plot API，Nuitka 打包后 < 30MB。控件不足处通过自定义 `draw_text` + `draw_rect` 逐行绘制弥补。

## 理由
- GPU 加速是高频数据刷新（终端 + 波形）的核心保障。
- 内置 Plot API 省去第三方绘图库集成。

## 后果 / 风险
- **中文字体** → 更纱黑体（Sarasa Gothic）等宽字体；需确认覆盖 CJK + 框线 + 等宽 Latin + 终端符号（ADR-0017）。
- **复杂布局** → 自研布局管理器封装。
- **大量文本性能** → 虚拟化渲染（只渲染可见行）。
- **最大单一技术风险**：DPG 能否当好终端渲染器。开工前必须先做终端渲染 spike（ADR-0017，O3）。
- **维护状态**：确认 DPG 2026 年活跃维护、与 Python 3.13 兼容（ADR-0017）。
