# 编码规范

## 风格（机器可验，R8）
- 代码用 `ruff` 检查 + `ruff format` 格式化（兼容 Black），line-length 100。
- 类型用 `mypy --strict`（含 `pydantic.mypy` 插件）。
- 命名：代码英文 snake_case；文档可中文，术语首次附英文（glossary 为准）。

## 数据流纪律（R9，ADR-0015）
- **任何引擎不得修改共享原始流**。各引擎解析自己订阅的那份流。
- **跳过字节只推进绘图本地游标**，不写回原始流。
- 智能分包只作用于日志/文件路径，不改原始流。

## 错误处理
- 解析/解码**绝不抛异常导致崩溃**：二进制流用 `errors="replace"`，未知序列静默跳过 + 记录日志。
- 配置/文件加载失败回退默认 + 日志，不崩溃。
- 关键路径（热循环）避免分配/深拷贝（性能纪律）。

## 性能纪律
- **先正确再快**；不提前优化。
- 实时数据不在热路径加缓存/无界缓冲。
- 各引擎后台线程 + 双缓冲 + 帧同步（ADR-0015）。
