# 完成的定义（Definition of Done）

任务卡在满足以下全部条件才可标记完成（R3：完成标准机器可验，不存在"我觉得完成了"）。

- [ ] 任务卡「目标/产出」全部实现，「禁止事项」未违反
- [ ] 相关单元测试通过且覆盖新增代码
- [ ] `ruff check` / `ruff format --check` / `mypy --strict` 通过
- [ ] CI 全部 job 绿
- [ ] 数据流不变量满足（原始流未被修改，ADR-0015 / R9）
- [ ] 涉及契约的任务，pydantic 模型与 schema 一致（漂移校验通过）
- [ ] 里程碑验收脚本通过（若该任务属某里程碑）
