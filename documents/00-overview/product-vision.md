# MAXCOM 产品愿景

> 一站式串口/网络调试与数据可视化平台。代号 **MAXCOM**，正式名待定。

## 1. 一句话定位

解决现有调试工具的**几乎所有痛点**：既有 SecureCRT 般的交互式终端（完整 ANSI），又有 VOFA+/SerialPlot 般的日志分析与绘图能力，还有 SSCOM/SuperCom 的协议调试便利——一个工具搞定串口/网络调试全流程。

## 2. 痛点来源（从现有工具出发）

| 工具 | 借鉴的优点 | 要解决的痛点 |
|---|---|---|
| VOFA+ | 显示串口名称、Linux Shell 颜色、绘图 | 时间戳解析差（空闲分包不可配，printf 被截断）、缺保存/命令列表、绘图协议难写、无交互终端 |
| SuperCom | 别名 + 记忆波特率、等宽字体、语法高亮 | 缺 ANSI 转义（实时更新闪屏）、缺日志过滤 |
| SSCOM | 收文件、UDP/TCP、定时发送、CRC、发文件 | 仅 GBK 编码、不能屏蔽蓝牙串口、缺 WINUSB/HID |
| SerialPlot | 最好的绘图：Simple Binary/ASCII/自定义帧、跳过1字节对齐 | 缺 FFT/Bode、缺自定义统计（均值/方差/PPM） |
| SecureCRT | 终端模拟器、XYZmodem、自动重连 | 缺绘图/命令列表/日志过滤等 |

## 3. 核心能力（对应 documents/03-modules 各模块）

- **双模式显示**：交互式终端（完整 ANSI 渲染 + 击键直传 + 本地回显）+ 传统收发分离（时间戳/自动染色/过滤）。侧边栏切换，连接不断。
- **各引擎独立解析原始流**：终端/日志/绘图/文件各自订阅同一份原始字节流，后台独立解析（ADR-0015）。
- **智能分包时间戳**：空闲超时可配，printf 不再被截断（独立开关）。
- **自动染色**：无 ANSI 时按预设规则（等级括号/关键词/键值对/数值）给日志行着色；检测到 ANSI 自动让位。
- **数据可视化**：波形/柱状/FFT/Bode/统计仪表盘（借鉴 SerialPlot）。
- **传输层**：串口（含别名/记忆/黑名单/热插拔/自动重连）、TCP/UDP、后续 WINUSB/HID。
- **自定义命令系统**：命令列表、定时发送、变量替换、自动校验。
- **Project 系统**：`.maxcomprj`（ZIP）一键保存/恢复完整调试环境。
- **插件系统**（Phase 4）：传输/协议/可视化/处理器/导出器。

## 4. 平台与范围

- Phase 0-5 **仅 Windows**；架构保持跨平台可移植性，后续支持 macOS/Linux。
- **单连接 + 多实例**：每个应用实例连接一个端口；多端口需求通过启动多个实例满足（ADR-0016）。
