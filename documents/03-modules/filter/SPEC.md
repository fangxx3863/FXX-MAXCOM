# 过滤引擎模块（filter / FLT）

> 状态：接近规格 ｜ 依赖：_foundation
> 对应 V2 §1.2 模式B + §1.4。日志行过滤（显示/隐藏），规则为正则。

## 1. 定位
按用户定义的正则规则过滤日志行：显示匹配行或隐藏匹配行。支持多规则链。过滤在**染色之后**执行（颜色标签已附加，过滤不影响颜色，INV-1）。

## 2. 组件

### 2.1 过滤引擎（filter_engine）
- 规则链：每条规则 `pattern` + `action`(show/hide) + `enabled`。
- 判定一行是否显示：默认显示，遇到 hide 规则匹配则隐藏；show 规则用于白名单。

### 2.2 规则定义（rules）
- 从 `02-contracts/filter-rule.schema.json` 定义（name/pattern/action/enabled）。

## 3. 关键不变量
- **INV-1**：过滤在染色后，不影响颜色标签。
- **INV-2**：被过滤行仍会染色（颜色标签已附加，用于文件保存——是否落盘见 O2）。
- **INV-3**：过滤只影响"显示"，不影响原始流（数据在原始流层面不可变，ADR-0015）。
