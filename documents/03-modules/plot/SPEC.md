# 绘图引擎模块（plot / PLT）

> 状态：接近规格 ｜ 依赖：_foundation
> 对应 V2 §1.7 + §4.3。借鉴 SerialPlot 并超越：波形/柱状/FFT/统计。订阅原始字节流，不受智能分包影响（ADR-0015）。

## 1. 定位
绘图引擎消费**原始字节流**（未分包），解析为通道采样数据，供波形/柱状/FFT/统计显示。帧解析用**本地游标对齐**，"跳过1字节"只影响绘图自身状态，不影响其他消费方（ADR-0015）。

## 2. 组件

### 2.1 数据源 + 环形缓冲（data_source / ring_buffer）
- RingBuffer 缓存原始字节，可配置点数。
- 订阅事件总线原始流（非分包流）。

### 2.2 帧解析器（parsers）
- **Simple Binary**：通道数 + 数据类型（int8~float64）+ 端序。
- **ASCII 分隔**：分隔符 + 过滤前缀。
- **自定义帧**：帧头/帧尾/帧长 + 数据类型 + 端序 + 校验（Checksum/CRC）。
- **数据错位跳过**：本地游标跳过1字节重新对齐。

### 2.3 通道管理（channels）
- 通道过滤/颜色/名称，独立设置。
- 自动 Y 缩放 / 固定范围。

### 2.4 显示渲染器（waveform / bar / fft / scatter）
- 波形图（滚动，缩放拖拽）、柱状图、FFT（1024~65536 点，Hann/Hamming/Blackman）、散点图。

### 2.5 统计（processors/statistics）
- 均值/标准差/方差/峰峰值/RMS/PPM/最大最小/自定义公式。

## 3. 关键不变量
- **INV-1**：绘图订阅原始流，不经分包（不受分包截断影响）。
- **INV-2**：跳过1字节只推进绘图解析器本地游标，不写回原始流，不影响其他消费方。
- **INV-3**：绘图引擎独立线程运行，帧解析为纯函数式（bytes → 采样）。
