# ANS-T09: 未知序列容错

> 模块：ansi ｜ 依赖：ANS-T01

## 目标
实现未知/不支持序列的容错：记录日志 + 静默跳过，绝不崩溃（INV-1）。

## IMPL `[骨架]`

### 签名
```python
class AnsiParser:
    def feed(self, data: bytes) -> None: ...
        # 逐字节状态机，遇未知序列进入跳过态，最终回归 GROUND
    def unknown_seq(self, seq: bytes) -> None: ...
        # 记录日志（应用自身日志），不抛异常
```

### 关键设计
- 状态机必须有从任何状态回归 GROUND 的路径（防挂起）。
- DCS/SOS/PM/APC 等不实现的序列进入跳过态，遇到终止符回归 GROUND。
- 跳过态处理要防 DoS（超长序列，如 ESC 后跟超长参数，需上限）。

### 易错点
- **超长/畸形序列**：`CSI 9999999...` 参数溢出处理；跳过态设上限（如 4096 字节）。
- 多字节序列在 TCP 分包边界被拆断：feed 需处理跨片段状态（解析器有状态，非一次性）。

### 完成标准（DoD）
- [ ] 未知序列不崩溃、回归 GROUND
- [ ] 超长序列安全跳过
- [ ] 跨片段解析（分包边界）正确

## 禁止事项
- 遇到未知序列不打印乱码到终端（静默跳过，记录日志）
