# T0-T02: lint / format / type 配置

> 模块：_foundation ｜ 依赖：T0-T01

## 目标
配好 ruff（lint + format）、mypy（strict）、pre-commit，使代码风格机器可验（R8）。

## IMPL `[详细]`

### 文件结构
- `ruff.toml` — line-length 100、选 flake8/isort/pyflakes 规则
- `mypy.ini` — `strict = true`
- `.pre-commit-config.yaml` — ruff、ruff format、mypy
- `tools/check-deps.py` — 扫 src/ import，白名单外 = exit 非 0

### 易错点
- mypy strict 对 pydantic v2 模型需额外配置（`[tool.mypy] plugins = ["pydantic.mypy"]`）。
- ruff format 与 black 兼容，锁版本避免与 CI 漂移。

### 完成标准（DoD）
- [ ] `ruff check src/`、`ruff format --check src/`、`mypy src/` 在空骨架通过
- [ ] `python tools/check-deps.py` 对白名单内 import 通过
- [ ] pre-commit 安装可用

## 禁止事项
- 不开严格模式（strict）、不加白名单外规则
