### 伪代码
```
detect(data):
    if data.startswith(utf-8 BOM): return "utf-8"
    if strict utf-8 解码成功: return "utf-8"
    # 含 >0.5 概率的 GBK 双字节特征（如连续两个 0x81-0xFE）
    if gbk 特征: return "gbk"
    return "auto"          # 兜底 latin-1 / 提示用户手动选
```

### 易错点
- **decode 绝不抛异常**（errors="replace"），二进制数据流不能崩。
- 自动检测是启发式，**不保证 100%**——UI 需给手动覆盖入口。
- 分行/分包在解码**之前**还是**之后**要定：先按字节分包（日志引擎），再整行解码。
