# T0-T08: DPG 终端渲染 spike（ADR-0017，开工前置验证）

> 模块：_foundation ｜ 依赖：T0-T07 ｜ **全项目最大的单一技术风险验证**

## 目标
用 DPG 原型验证能否当好"终端渲染器"：60fps 彩色滚动终端、CJK 宽字符对齐、框线覆盖、维护状态。验证通过则 ADR-0017 转 accepted；不通过提新 ADR 变更选型。

## IMPL `[详细]`

### 原型内容（tools/spike_terminal.py）
1. **性能**：用 `draw_text` 逐行渲染一个 50 行 × 100 列的彩色终端，模拟 3Mbps 数据注入，测帧率是否稳定 ≥ 30fps。
2. **CJK 对齐**：渲染中文半宽/全宽混排文本，验证列对齐（`draw_text` 定位 vs 字符宽度）。
3. **框线覆盖**：渲染 `─ │ ┌ ┐ └ ┘ ├ ┤` 框线字符 + 终端符号，用更纱黑体确认无缺字方块。
4. **维护状态**：查 DPG 是否 2026 活跃维护、兼容 Python 3.13。

### 易错点
- DPG `draw_text` 无富文本，多色需多次调用，测试调用开销。
- CJK 宽字符在终端网格中占 2 列，绘制定位需乘列宽——验证算法。
- 单字体图集缺字即方块，字体选择是关键。
