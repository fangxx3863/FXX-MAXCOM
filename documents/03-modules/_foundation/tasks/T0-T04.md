# T0-T04: 事件总线（单一原始流扇出）

> 模块：_foundation ｜ 依赖：T0-T01

## 目标
实现 Pub/Sub 事件总线，承载 **单一原始流扇出**（ADR-0015）：每个消费引擎订阅同一份原始字节流，独立处理。

## IMPL `[详细]`

### 签名
```python
class EventBus:
    def publish_raw(self, data: bytes) -> None: ...
        # 对每个订阅者逐份拷贝原始流，入各自队列
    def subscribe(self, subscriber: str) -> queue.Queue[bytes]:
        # 返回该订阅者独占的原始流队列；同一实例所有订阅者收到相同数据
    def unsubscribe(self, subscriber: str) -> None: ...
```

### 伪代码
```
publish_raw(data):
    for q in self._queues.values():
        q.put(data)          # 逐份拷贝，各队列独立

subscribe(name):
    q = Queue(maxsize=BUFFER_LIMIT)   # 有界，防消费慢的订阅者拖死
    self._queues[name] = q
    return q
```

### 易错点
- **队列必须有界**：某引擎消费慢时不能无限膨胀。满时策略：丢最旧（记录日志）。
- 原始流逐份拷贝，**不得共享可变缓冲**——否则一个引擎消费会互相干扰（R9）。
- publish 不能阻塞生产端（I/O 线程）：满队列处理要 O(1) 且不等待。

### 不变量
- 所有订阅者收到**相同序列**的原始字节（顺序一致）。
- 一个订阅者消费不影响其他订阅者的数据。

### 完成标准（DoD）
- [ ] 单生产者多消费者：各消费者收到相同数据、顺序一致
- [ ] 慢消费者不阻塞生产端（满队列丢最旧 + 计数）
- [ ] 单元测试覆盖：多订阅者、慢消费者、退订

## 禁止事项
- 不做任何解析/分包——事件总线只负责扇出原始流
