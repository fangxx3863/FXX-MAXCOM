# T0-T06: 全局配置管理

> 模块：_foundation ｜ 依赖：T0-T03

## 目标
实现全局配置 TOML 读写 + pydantic 校验（`%APPDATA%/MAXCOM/config.toml`，ADR-0003）。

## IMPL `[详细]`

### 签名
```python
class ConfigManager:
    def __init__(self, path: Path): ...
    def load(self) -> GlobalConfig: ...          # 文件缺失→默认配置
    def save(self, cfg: GlobalConfig) -> None: ...  # 临时文件+rename，原子写
    @property
    def path(self) -> Path: ...
```

### 易错点
- **原子写**：先写 `config.toml.tmp` 再 rename，避免写坏文件。
- 文件缺失/损坏时回退默认配置，不崩溃，并记录日志。
- 全局配置只存与项目无关的个人偏好（主题/语言/字体/端口黑名单/别名/记忆）。

### 完成标准（DoD）
- [ ] 首次运行生成默认 config.toml
- [ ] 修改后保存，重载保持一致
- [ ] 损坏文件回退默认 + 日志
- [ ] 原子写测试（模拟中断不残留损坏文件）
