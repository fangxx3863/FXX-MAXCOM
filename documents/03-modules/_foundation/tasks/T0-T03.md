把 `02-contracts` 的 schema 用 pydantic v2 定义同构模型，作为业务模块的共享依赖（R6）。

### 签名
```python
# 每个模型用 pydantic BaseModel，字段与 schema 完全一致
class Command(BaseModel):
    name: str
    group: str = ""
    data: str
    format: Literal["text", "hex"] = "text"
    shortcut: str = ""
    repeat: Repeat | None = None
    expect: str = ""
    timeout_ms: int = 0
```

### 易错点
- **字段名与 schema 完全一致**，否则契约漂移。
- 绘图 data_format 是 discriminated union（`type` 字段分派），用 `model = Field(discriminator="type")`。
- 添加一个 CI 校验脚本读 schema 与模型对比字段集（防漂移）。
