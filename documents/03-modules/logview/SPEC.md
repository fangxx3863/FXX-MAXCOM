# 传统收发模块（logview / LOG）

> 状态：接近规格 ｜ 依赖：_foundation、colorize、filter
> 对应 V2 §1.2 模式B + §1.5 + §1.9。日志引擎：智能分包 + 时间戳 + 分行 + 染色 + 过滤 + 落盘。

## 1. 定位
传统收发分离模式（Log View + Send Panel）。作为**日志引擎**消费原始字节流：智能分包（空闲超时）→ 分行（`\r\n`）→ 时间戳 → 自动染色 → 过滤 → 显示/落盘。智能分包是日志/文件路径的本地行为（ADR-0008, ADR-0015）。

## 2. 组件

### 2.1 智能分包 + 时间戳（timestamp_manager）
- 按空闲超时（10ms~500ms，可配）切分数据帧，每帧一个时间戳。
- 独立开关（ADR-0008）：关闭则透传，不封包不加时间戳（或按行加）。
- 时间戳格式：绝对 `HH:MM:SS.ms` / 相对 `+ms` / 差值 `Δms`。

### 2.2 分行（log_buffer）
- 正确解析 `\r\n` / `\n` / `\r` 为行（ADR-0014，不依赖分包）。
- 固定上限 10 万行，超出丢弃旧行（ADR-0010）。
- LogEntry 结构：时间戳 + 文本 + 颜色标签 + 原始字节。

### 2.3 组装（logview engine）
- 原始流 → 分包+时间戳 → 分行 → 染色（colorize）→ 过滤（filter）→ 产出 LogEntry。
- 数据到达顺序：**先染色后过滤**（INV-1）。

## 3. 关键不变量
- **INV-1**：先染色后过滤；被过滤行仍染色（用于文件，见 O2）。
- **INV-2**：`\r\n` 分行始终生效，不依赖分包（分包只加时间戳）。
- **INV-3**：分包/过滤只影响日志路径，不影响原始流（ADR-0015）。
- **INV-4**：日志引擎在独立后台线程运行，与终端/绘图互不阻塞。

| 卡 | 标题 | blocked-by |

| LOG-T03 | 日志引擎组装（分包→分行→染色→过滤） | LOG-T01, COLOR-T01, FLT-T01 |
