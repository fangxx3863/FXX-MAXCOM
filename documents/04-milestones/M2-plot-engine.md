# M2: 绘图引擎

目标：能像 SerialPlot 一样绘图，还能做 FFT。

## 交付清单
1. **数据源 + 环形缓冲**（PLT-T01）：订阅原始流，不受分包影响。
2. **帧解析器**（PLT-T02/03/04）：Simple Binary / ASCII 分隔 / 自定义帧。
3. **数据错位跳过**（PLT-T05）：本地游标对齐，不影响其他消费方。
4. **通道 + 波形/柱状**（PLT-T06）。
5. **FFT**（PLT-T07）+ **统计仪表盘**（PLT-T08）。
6. **绘图配置 + Viewport**（PLT-T09）。

## 退出标准（验收演示脚本）
- 造一段 Simple Binary 数据流（如正弦 + 方波），绘图正确显示波形/柱状。
- 人为错位 → 点"跳过1字节"几次对齐，且终端/日志数据不受影响。
- FFT 对已知正弦显示正确峰。
- 统计仪表盘显示均值/RMS 等正确。
