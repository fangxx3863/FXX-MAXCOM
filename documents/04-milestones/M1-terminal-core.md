# M1: 终端核心

目标：能用终端模式操作 Linux 板卡，能用传统模式调试协议。

## 交付清单
1. **ANSI 解析引擎**（ANS-T01..09）：SGR + 光标 + 擦除 + 滚动区域 + 屏幕缓冲 + 回滚 + 容错。
2. **交互式终端**（TERM-T01..07）：DPG 渲染 + 击键直传 + 控制字符 + 本地回显 + 选择复制 + 粘贴 + 回滚查看。
3. **传统收发**（LOG-T01..03）：智能分包/时间戳 + 分行 + 染色 + 过滤 + 编码。
4. **自动染色 + 过滤**（COLOR 全部，FLT 全部）。
5. **双模式切换**：侧边栏切换，连接不断。

## 退出标准（验收演示脚本）
- 连虚拟串口（com0com），板卡模拟器输出 ANSI 彩色文本 → 终端模式正确渲染。
- 用交互终端执行 `ls`/`cat` 等（模拟远端），击键直传 + 本地回显可选。
- 传统模式：分包时间戳正确，`[E]` 行红色，过滤只显 `[I]`，`\r\n` 分行正确。
- 双模式切换连接不断。
